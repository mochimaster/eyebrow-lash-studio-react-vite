# Image sources

This practice project uses remote images from Unsplash rather than bundling the original Weblium template images.

The image URLs used in the site are from these Unsplash photo pages:

- Close-up of a human eye with detailed eyelashes and eyebrow — Zoe Denney-Goodyer
  https://unsplash.com/photos/close-up-of-a-human-eye-with-detailed-eyelashes-and-eyebrow-otYarkxbZzo

Some of the team/beauty placeholder photos are older Unsplash image URLs inherited from the earlier practice version. Replace all remote image URLs with your own licensed portfolio photos when turning this into a real business website.

Unsplash licenses can change for individual assets, and Unsplash+ images may require a paid license. Check the individual photo page before using an image commercially.
